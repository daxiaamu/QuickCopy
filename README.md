# QuickCopy

[机场推荐：白月光，稳定高速](https://www.sibker.com/register?invite_code=2XQR1UUz)

轻量级 Windows 剪贴板快捷发送工具。

一键复制常用文本/链接到剪贴板。按钮宽度自适应内容，支持 DPI 缩放、GBK/UTF-8 自动识别。

## 功能

- 从 `links.json` 异步加载常用文本/链接，显示为按钮
- 点击按钮自动复制内容到剪贴板
- 按钮宽度自适应文字长度
- 鼠标悬停高亮效果
- 高 DPI 支持（微软雅黑 10pt）
- 单实例运行
- 系统托盘常驻服务
- 首次运行默认启用开机自启，登录后静默驻留托盘，可在托盘右键菜单关闭
- 支持绑定键盘触发键、组合键和鼠标右键/中键/侧键启动主面板
- 安装可选键盘过滤驱动后，焦点位于 ToDesk 等远程设备时，本机物理触发键仍可唤出主面板（需要管理员安装、重启和有效驱动签名）
- 托盘右键可开启/暂停快捷键监听、设置触发键、退出
- 双击托盘图标可打开主面板
- 主面板聚焦时 Ctrl+W 或关闭窗口会隐藏主面板，托盘菜单“退出”才会结束程序

## 触发模式

发布给用户时只需要一个 `QuickCopy.exe`，驱动包已嵌入可执行文件。

- 普通模式：无需管理员权限和重启，使用用户态监听；焦点位于远程软件时不保证触发。
- 增强模式：首次启用时由 QuickCopy 请求管理员权限并安装键盘过滤驱动，重启一次后可在 ToDesk 等远程软件聚焦时响应键盘触发键。
- 鼠标触发键始终使用普通模式。

首次录制触发键时可以选择模式，之后可在触发键设置窗口中随时切换。增强模式的公开发布版本必须嵌入微软认可签名的驱动包，测试证书仅用于开发验证。
## 编译

需要 MinGW-w64：

```bash
build.bat
```

`build.bat` 会把 `driver/x64/Release` 中的 SYS/INF/CAT 包嵌入 `QuickCopy.exe`。驱动开发与签名流程参见 `driver/README.md`。

## 使用

在 exe 同目录下放 `links.json`（格式见下方），运行 QuickCopy.exe 即可。

触发键配置会保存到同目录下的 `quickcopy_hotkey.ini`。首次启动不会占用默认快捷键，需要在托盘菜单里自行设置。

### links.json 格式

```json
[
    {
        "name": "按钮名称",
        "content": "点击后复制的内容"
    }
]
```

支持 UTF-8 和 GBK 编码（自动检测）。

当前轻量解析器面向固定格式使用：最多读取 256 个按钮，单个 `name` 或 `content` 最多 4095 个宽字符。
